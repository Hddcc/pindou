# 老派拼豆之必要 MVP

手机、平板优先的响应式 Web/PWA。前端 React 19 + TypeScript + Canvas，后端 Go + SQLite。无需付费云数据库、短信或对象存储服务。

iPadOS 14.7.1 的适配检查、HTTPS 发布、添加到主屏幕及断网验收步骤见 [iPad 安装与离线使用](deploy/IPAD_INSTALL.md)。

应用图标使用 `assets/app-logo.jpg` 中的原图。安装前端依赖后，运行 `node scripts/generate-icons.mjs` 可重新生成网页、iPad 和 PWA 的 PNG 图标；生成结果随源码提交，服务器正常构建无需另行生成。已有主屏幕入口的名称与图标更新方法见安装说明。

## 本地启动

需要 Node.js 22+、Go 1.24+。首次安装依赖：

```powershell
npm --prefix web ci
cd server
go mod download
cd ..
npm run dev
```

打开终端输出的 Local 地址，默认 `http://localhost:5173/`。启动脚本自动选择空闲端口，同时启动前端和 Go API；Ctrl+C 停止服务。根目录无需单独执行 `npm install`。

手机和平板连接同一 Wi-Fi 后可打开终端的 Network 地址。电脑需允许该端口通过防火墙；请自行确认网络权限。局域网 HTTP 支持画板、本地文件和云保存，PWA 安装与离线缓存需要 HTTPS。不同访问地址拥有独立的浏览器本地作品缓存。

本地预览正式构建（包含 PWA）：

```powershell
npm start
```

默认地址 `http://localhost:4173/`，由 Go 同时提供网页和 API。`npm start` 和 `npm run dev` 共用数据库，请先停止上一种模式。两种启动脚本仅用于本地测试，使用非 Secure Cookie；公网部署使用下面的 HTTPS 配置。

## 已实现

- MARD291 真实色号，按 A、B 等色号前缀分区排列，支持搜索、色系筛选、最近使用颜色，显示补齐色号（如 F09）。
- 1–200 格自定义宽高及 16/32/64/96/128 预设。
- 连续画笔、填色、1×1/2×2/4×4/8×8 橡皮擦、画布取色、100 步撤回/反撤回；画笔按钮内可切换“画笔 / 填色”，橡皮保留最后一整笔实际擦除区域的外轮廓虚线。
- 外部屏幕取色、上传图片点取色、HEX/RGB 输入；原色和 3 个相近 MARD 色可自主选择，自定义颜色兼容本地文件与云保存。
- 白灰棋盘底色、四边逐格连续标尺、格内色号开关；普通线和辅助线分别调整实线/虚线与深浅，辅助线支持每 5/10 格，中心十字线可关闭或改色。
- 自动更新每种已用颜色的颗数，支持数量/色号排序；清空确认、水平/垂直镜像均可一整步撤回。
- 只读拼豆模式：逐个筛选已用颜色，其他色块和色号隐藏，支持全部颜色、缩放和平移；从本机、云端或文件打开时可直接进入。
- 矩形选区、整格拖动色块、删除选区颜色、移动与删除撤回；PNG 可导出完整画布或当前选区，区域导出仅统计选区用色。
- 视口四边固定标尺带，缩放和平移后逐格显示当前可见坐标；绘图工具与色板入口合并到底部，色板向上展开，不压缩画布；撤回、重做、保存和导出集中在顶部“画布操作”菜单中。
- 单指绘图、双指缩放和平移、鼠标滚轮、平移工具、适配画布和 100% 视图。
- 800 ms 防抖自动保存、10 秒兜底、切后台保存、同步恢复副本、刷新恢复、本机多作品列表，显示自动保存时间。
- 下载/重新打开可编辑 `.pindou` 文件；损坏文件不会替换当前作品。
- 用户名密码注册登录、私有云作品保存/打开/重命名/删除/另存为。
- 创建请求幂等、多账号引用隔离、版本冲突选择、网络失败保留本机修改。
- 两种 PNG 预览与下载：带完整网格棋盘底色/四边标尺/色号、无网格透明底，每格 20 px；可在下方附加总颗数及每种颜色的颗数统计。
- 正式构建提供主屏幕图标、应用清单、编辑器静态缓存与更新提示。API 走网络，不缓存账号与云作品。
- Safari 14 兼容：实际可见高度随浏览器工具栏与横竖屏更新，外层编辑页禁止滚动；本机草稿复制不依赖 `structuredClone`，弹窗提供焦点限制、关闭与焦点恢复的兼容实现。

自动恢复最近作品；新建或打开其他作品前会保存当前草稿，原作品留在本机列表。临时保存失败时要求确认。云保存采用手动操作，浏览器临时保存始终自动进行。游客作品不上传服务器。

### 新增功能入口

底部工具栏的“画布”图标调整网格、中心线颜色和格内色号开关，设置保存在当前浏览器，也用于带网格 PNG 导出。关闭格内色号不会隐藏色板、统计和拼豆颜色选择栏的编号。

点击底部“橡皮擦”工具，按钮上方展开尺寸选项，默认 1×1，可选择 2×2、4×4、8×8；选择后收起，再点橡皮擦可调整尺寸，按钮角标显示当前尺寸。一次拖动擦除对应一次撤回，偶数尺寸以当前格向左/上偏半格定位，超出画布的部分自动裁剪。松开后保留这一整笔实际擦掉格子的并集外轮廓，包括不规则形状、分离区域和孔洞，空白格不计入；新笔划替换旧轮廓，新修改或撤回清除轮廓，重做擦除可恢复。轮廓仅为临时提示，不保存、不导出。

工具栏的滴管图标打开外部取色。支持 EyeDropper API 的桌面浏览器可以直接取屏幕颜色，需要 HTTPS 或 localhost；手机/平板可从相册选择截图或图片，再点击图片取色，也可输入 RGB/HEX。浏览器限制了移动端跨应用直接取色。原始 RGB 和 HEX 始终保留，下方按 CIEDE2000 感知色差推荐 3 个启用中的 MARD 颜色，相同 HEX 合并为一个推荐。点击原色或推荐色，再确认使用；修改取色值后自动回到原色选项。保留原色时，与 MARD291 的 HEX 完全匹配则使用对应色号，其他颜色保存为 `#RRGGBB`，界面和统计显示 RGB；格内 HEX 采用两行排版。推荐仅用于屏幕预览，实际拼豆请核对实物色卡。图片取色最多 20 MiB / 4000 万像素，使用原始像素取色。

打开外部取色框前会等待本机草稿保存完成；保存失败时保留当前画板并显示错误。启动相册选择前再写入同步恢复副本。取消选择图片会保留取色框，点击关闭可返回同一画板。图片预览的最长边限制为 1600 px，实际取色仍读取原图坐标的单个像素，减少大画布缓冲区占用；触屏输入框使用 16 px 字号，避免 Safari 输入时自动放大。原生相册切换和内存回收行为仍需 iPad 真机验收。

选择工具栏的“选区”，从一个格子拖到另一个格子进行矩形框选；再次从框内拖动即可整格移动其中的色块，松开后提交为一个撤回步骤。目标区已有色块被移入的有色格覆盖，选区中的空白格保持透明；移动范围限制在画布内。框外重新拖动可建立新选区，选区旁的关闭图标取消框选。双指缩放或指针取消会取消当前拖动，不更改作品。选区仅在当前编辑会话中保留；撤回、重做、新建或打开作品后清除选区。选区操作不会改变画布尺寸。

框选后，点击选区浮条的垃圾桶图标“删除选区颜色”，确认后清空选区内颜色，选区外保持不变；操作作为一个撤回步骤并自动保存，删除后保留选框。空白选区的删除按钮禁用。

“导出”弹窗的“导出范围”可选择完整画布或当前选区，也可从选区浮条直接进入。选区导出保留矩形区域内的空白格，坐标从 1 重新编号，统计仅包含选区的豆子；本地 `.pindou` 文件和云端保存始终保留整幅作品。

桌面、平板和手机共用底部工具栏，从左到右包含移动、画笔、橡皮擦、画布取色、选区、外部取色、画布设置和当前颜色入口。点击画笔可切换“画笔 / 填色”，点击橡皮擦可选择 1×1、2×2、4×4 或 8×8。点击右侧色块向上展开色板，关闭图标或点击浮层外收起；宽屏将颜色网格与筛选控件并排显示，窄屏显示紧凑抽屉。浮层开关不改变画布尺寸及缩放位置，横竖屏均可使用。顶部“画布操作”菜单收纳绘图/拼豆模式、撤回/反撤回、统计、镜像、清空、保存和导出。四边固定标尺显示当前视野内的连续格号，平移后更新到对应坐标。

顶部“画布操作”菜单中的统计入口会在底部展开“用色统计”；绘制、擦除、撤回、重做、清空和镜像完成后自动更新，点击统计行可选择绘图颜色。镜像入口分别水平、垂直翻转整个画布；清空入口会二次确认，操作后可撤回。空画布禁用镜像和清空。

顶部“画布操作”菜单切换“绘图模式 / 拼豆模式”。拼豆模式提供横向已用色选择栏，点击某色后仅显示该颜色，统计仍包含全图，保存和导出也保留完整作品；点击“全部颜色”或切回绘图即可恢复。拼豆模式禁用绘图、撤回、镜像和清空，可继续缩放和平移。在“我的作品”中勾选“以拼豆模式打开”后，再打开本机作品、云作品或本地 `.pindou` 文件。PNG 仍是分享图片，当前不支持导入 PNG 转成可编辑拼豆图。

每次结束绘制会立即尝试写入同步恢复副本，随后写入 IndexedDB；后台与退出前也会尝试保存。自动保存只保存在当前设备的浏览器中，云端仍需手动保存。清理网站数据、存储权限不足或浏览器强制终止仍有丢失风险，重要作品请下载文件并保存云端。

导出默认附加用色统计，可以取消勾选。透明背景模式只导出色块；统计栏使用白底并保留上方的透明区域。网格模式加 24 px 四边标尺，开启统计时图片宽度至少 320 px，让长 RGB 标签有足够空间；关闭统计的透明模式保持画布原始导出尺寸。

## 数据与限制

服务器数据文件：`server/data/pindou.db`，包含账号、会话、色库、云作品；SQLite WAL 文件由数据库管理。停止服务后才能直接复制完整数据库文件，运行中请使用备份命令。

浏览器临时作品存储在 IndexedDB，清理网站数据、隐私浏览或系统回收空间可能导致丢失，请定期下载 `.pindou` 或保存云端。PNG 用于查看与分享，继续编辑请使用作品文件。

用户名为 3–32 位字母、数字、下划线（统一小写），密码 8–72 个字符。当前不支持找回密码。每个账号最多 200 个云作品，单快照最多 2 MiB、JSON 请求 3 MiB。空格不占用稀疏格子记录。单机 SQLite 面向小规模使用，公网发布前需结合服务器资源评估并发及防滥用策略。

色库为开源社区整理，详见 `THIRD_PARTY_NOTICES.md`。HEX 为屏幕预览色，请以实际拼豆色卡为准。

## 测试和构建

```powershell
npm test
npm run build
cd server
go vet ./...
go build -o bin/pindou-server.exe ./cmd/server
```

`npm test` 运行 Go 接口/领域/密码测试和 Vitest 编辑/IndexedDB/可见视口测试。`web/e2e` 提供可重复的浏览器测试，可在安装 Playwright Chromium 和 WebKit 后运行：

```powershell
cd web
npx playwright install chromium webkit
npm run test:e2e
```

运行 E2E 前在另一终端启动 `npm run dev`。默认 `E2E_BASE_URL=http://localhost:5173`，使用独立的浏览器测试上下文，不读取个人账号。本版本尚需真机确认 iOS 下载/文件导入、双指手势和添加到主屏幕。

离线测试需要先运行 `npm run build`，它单独启动临时静态服务，在完成缓存后关闭服务并验证缓存响应、本机恢复与下载，不会关闭正常运行的画板服务。Chromium 项目同时使用网络断开模拟；Windows WebKit 的驱动断网切换会报导航内部错误，因此 WebKit 使用关闭临时服务来验证服务器不可达后的缓存启动，iPad 飞行模式仍需按安装说明验收。

Windows 上的 Chromium 项目可以使用已安装的 Edge；新增的 Safari 引擎检查需下载 WebKit：

```powershell
$env:E2E_BASE_URL='http://localhost:4173'
$env:E2E_BROWSER_CHANNEL='msedge'
npx playwright install webkit
npm run test:e2e -- --workers=4
```

## 部署到云服务器

将 `web/dist` 部署为 `/opt/pindou/web`，Go 二进制部署为 `/opt/pindou/bin/pindou-server`。准备 Linux 用户 `pindou`，创建专用 `data`、`backups` 目录并授予该用户写权限；网页静态目录需对 Caddy 运行用户可读。

在目标 Linux 构建后端：

```sh
cd server
go build -trimpath -o bin/pindou-server ./cmd/server
go build -trimpath -o bin/pindou-backup ./cmd/backup
```

使用 `deploy/pindou.env.example` 配置 `/opt/pindou/pindou.env`，修改 `PUBLIC_ORIGIN` 为实际 HTTPS 域名，并保持 `COOKIE_SECURE=true`。生产监听回环地址，通过 Caddy 反向代理。`ADDITIONAL_ORIGINS` 默认留空，仅在确实需要额外受信地址时设置逗号分隔的精确 Origin。

`deploy/Caddyfile` 替换示例域名后交给 Caddy 使用；DNS 指向服务器并开放 80/443，Caddy 自动申请免费证书。`deploy/pindou.service` 提供 systemd 服务模板。现有服务器、流量和域名的费用取决于自己的套餐。

备份：在 `server` 目录执行 `go run ./cmd/backup -dir ./backups`，在线使用 SQLite `VACUUM INTO` 产生一致的快照。提供每日 systemd 备份模板；本 MVP 保留全部备份，请定期检查磁盘并自行制定保留策略。恢复前停止服务，保留现有数据，再将选定备份作为 `DB_PATH` 启动。

色库更新：在 `server` 执行 `go run ./cmd/colorimport -file ./data/mard291.json`；未出现的旧色号标记停用并保留历史引用，前端联网后读取与缓存完整色库。打包默认色库也应同步更新到 `web/src/data/mard291.json`。
